How the value is worked out

implied = (TVL / $1M)0.92 × $1M × category multiple × growth × maturity × breadth

Every factor comes from the snapshot alone: TVL, the seven-day change, how long the protocol has run with no token, and how many chains it is on. No protocol name is special-cased — the same formula scores every row, and each protocol's detail view shows its own five factors so you can check the arithmetic. The implied value is this radar's claim, not a prediction that a token will be issued or when.

A protocol is listed as pre-token when its record carries no token — no market cap, no CoinGecko id, no symbol. That is what its record says, never proof it has none.
