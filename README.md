A token launch radar: it scores every pre-token launch candidate in a sealed snapshot with a transparent model (lib/model.ts), ranks them into a board, and renders a static dashboard that sorts, filters and shows the evidence behind each score. Node 22 standard library only, no network.

## Run it

```sh
node main.ts --input <snapshot.json>
# writes board.json, the dashboard and its data, and dossier.json to the output dir
```
